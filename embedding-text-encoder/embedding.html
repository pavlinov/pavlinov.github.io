2D Projection / Проекция

Projects both 384-dim unit vectors into the 2D plane they actually span (Gram-Schmidt), draws them as arrows from origin on a unit circle, marks the angle arc with the exact degree value, and shows cos θ at the bottom. This is literally what cosine similarity means geometrically. Проецирует оба 384-мерных единичных вектора на 2D-плоскость, которую они образуют (метод Грама–Шмидта), рисует их как стрелки из начала координат на единичной окружности, отмечает дугу угла с точным значением в градусах и показывает cos θ внизу. Это буквально геометрический смысл косинусного сходства.

384 Points / Точек

Основа. Оба вектора — массивы из 384 чисел. Для каждой позиции i получается пара: (vecA[i], vecB[i]). График — все 384 таких пары, нарисованные точками. Ничего сложнее.

Оси. Ось X = «насколько Вектор A активирует измерение i». Ось Y = «насколько Вектор B активирует измерение i». Каждая точка задаёт вопрос: согласны ли оба предложения в этом понятии?

Диагональ. Пунктирная линия y=x — линия «полного сходства» (или линия тождества). Точка на ней означает одинаковое значение в обоих векторах для этого измерения. Если бы все 384 точки лежали на диагонали — косинусное сходство было бы 100%.

Форма облака. Плотный кластер вдоль диагонали → предложения похожи. Круглое облако → предложения не связаны. Чем вытянутее и диагональнее облако — тем выше сходство.

Цвета. Синий = оба положительные (оба активируют понятие). Красный = оба отрицательные (оба подавляют). Зелёный = разные знаки (одно активирует, другое — нет).

Главный вывод. Косинусное сходство математически эквивалентно корреляции между двумя наборами из 384 чисел. Этот график и есть косинусное сходство в визуальном виде — чем плотнее и диагональнее облако, тем выше итоговая оценка.

The setup. Both vectors are arrays of 384 numbers. For each position i you get a pair: (vecA[i], vecB[i]). The plot is all 384 of those pairs drawn as dots. Nothing more.

Axes. X = "how much does Vector A activate dimension i". Y = "how much does Vector B activate dimension i". Each dot asks: do both sentences agree on this concept?

Diagonal. The dashed y=x line is "perfect agreement". A dot on it means both vectors have the same value for that dimension. If all 384 dots were on the diagonal — cosine similarity would be 100%.

Shape. Tight cluster along the diagonal → sentences are similar. Circular blob → sentences are unrelated. The more elongated and diagonal the cloud — the higher the similarity.

Colors. Blue = both positive (both activate the concept). Red = both negative (both suppress). Green = opposite signs (one activates, the other does not).

Key insight. Cosine similarity is mathematically equivalent to the correlation between two sets of 384 numbers. This plot is the cosine similarity visualized — the tighter and more diagonal the cloud, the higher the score.
